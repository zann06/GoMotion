# UI Implementation Prompt

Implement GoMotion UI using `docs/DESIGN_SYSTEM.md`, `docs/UI_UX_GUIDELINES.md`, and the PNG references in `design/references/`. Match layout hierarchy, spacing, component behavior, and color tokens; do not treat references as permission to copy third-party assets.

Build reusable components before feature screens. Use safe areas, responsive constraints, semantic labels, 48dp touch targets, and scalable typography. Primary CTA uses restrained indigo/blue/violet treatment. Ensure loading, empty, disabled, selected, and error states. Every visible control must trigger a meaningful local action. Test key components and inspect overflow.
