# Product Overview

## What GoMotion is
A fictional, interactive ride-hailing experience simulator. It is designed to feel like a polished mobility app while keeping every operation local and explicitly simulated.

## Experience pillars
- **Clarity:** one obvious next action at each step.
- **Confidence:** show fare, route, driver, and order details before confirmation.
- **Delight:** purposeful micro-interactions and expressive transitions.
- **Honesty:** visible demo labels for money, people, and services.
- **Resilience:** the app works in airplane mode after installation.

## Information architecture
Home; Ride flow; GoFood; GoSend; Activity; Profile. Use a persistent bottom navigation for primary destinations, with flow-specific pages pushed through GoRouter.

## Terminology
Use “simulation”, “demo”, “fictional”, or “sample” where users could mistake a value for a real service. Avoid claims such as “driver is actually on the way”; prefer “Simulated driver arrival”.

## MVP boundary
The first complete demonstrable release includes home, local destination selection, ride booking, matching/tracking, demo payment, activity, and profile. GoFood and GoSend follow as separate roadmap phases.
