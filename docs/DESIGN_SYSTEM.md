# Design System

## Brand
GoMotion — “Move smarter. Feel every journey.” Original mobility-tech identity. Never use green as the primary brand color.

## Color tokens
| Token | Hex | Usage |
|---|---|---|
| primaryIndigo | #4F46E5 | Primary actions, active states |
| electricBlue | #2563EB | Links, secondary emphasis |
| violet | #8B5CF6 | Accent, gradient endpoint |
| deepNavy | #111827 | Main text / dark surfaces |
| softWhite | #F5F6FF | App background |
| white | #FFFFFF | Cards and sheets |
| neutralGray | #64748B | Secondary text |
| lightBorder | #E5E7EB | Dividers and outlines |
| success | #16A34A | Semantic success only |

## Typography
Use a modern sans-serif. Suggested hierarchy: display 28–32/700, title 22–24/700, section 16–18/650, body 14–16/400, caption 11–12/500. Use bundled fonts only if licensing permits; otherwise platform sans-serif.

## Layout
8-point spacing base. Screen horizontal padding 20–24. Card radius 20–24; button radius 16; chip radius 999. Minimum touch target 48×48 logical pixels. Respect safe areas.

## Components
Primary gradient button (indigo→blue→violet), tonal button, icon service tile, destination row, vehicle option, driver card, fare breakdown, promo card, status pill, map pin, bottom sheet, receipt row, empty state, skeleton.

## Elevation and effects
Use subtle shadows and restrained gradients. Avoid glow-heavy styling, broad blur, and stacked decorative effects. Prefer clear borders and surface contrast.

## Iconography
Consistent rounded line icons with 1.8–2.0 stroke. Create original GoMotion mark from a forward-motion path/chevron motif; do not approximate competitor marks.

## States
Default, pressed, focused, disabled, loading, selected, success, warning, and error. Every state must have sufficient contrast and semantic labeling.
